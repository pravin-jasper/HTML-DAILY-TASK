IndusInd Bank Credit Card Application Form
# Project Description
This is a simple HTML Credit Card Application Form created for learning and practicing HTML forms.
The form allows users to select a card type and enter details such as credit card number, email ID, mobile number, payment amount, and bank account.
> **Note:** This is an educational/demo project and is not an official IndusInd Bank website or payment system.

Bank Account	Select a bank account
