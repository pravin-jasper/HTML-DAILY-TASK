 # Spice Garden Restaurant

A simple HTML-only restaurant website for **Spice Garden**, featuring authentic Indian cuisine, menu items, chef information, food gallery, customer reviews, table reservations, and contact details.

## Features

- Home and welcome section
- About the restaurant
- Menu with starters, main course, breads, and desserts
- Today's specials
- Our chefs section
- Food gallery
- Customer reviews
- Table reservation form
- Contact information and opening hours
- Navigation links between sections

## Technologies Used

- HTML5

This project uses HTML only and does not require CSS or JavaScript.

## How to Run

1. Save the HTML code as `index.html`.
2. Open `index.html` in any web browser.
3. Use the navigation links to move between sections.
