# HTML Dropdown Selection
A simple HTML project containing dropdown menus for selecting locations and purposes.
Features
Location dropdown with the following options:
Udangudi
Thoothukudi
Tiruchendur
Purpose categories:
Emergency
Health
Personal
Simple and easy-to-use HTML structure.
Can be used as a starting point for forms or location-based service selection.
# HTML Structure
The project uses HTML `<select>` and `<option>` elements to create dropdown menus.
# Example:
```html
<td>
    <select>
        <option>Udangudi</option>
        <option>Thoothukudi</option>
        <option>Tiruchendur</option>
    </select>
</td>
```
# Purpose
The dropdown can be used to select the purpose of a request:
Emergency – For urgent requirements
Health – For healthcare-related requirements
Personal – For personal requirements
Project Structure
```text
project/
│

```
# How to Use
Clone or download this repository.
Open `index.html` in a web browser.
Select a location from the dropdown.
Select the required purpose.
