# Application Form

## 📋 Project Overview

This project is a simple **Application Form** created using **HTML5**.

The form allows users to enter their personal information and upload a file.

## ✨ Features

The application form contains the following fields:

* First Name
* Last Name
* Phone Number
* Email ID
* File Upload
* Date
* Time
* Submit Button

## 💻 Technologies Used

* HTML5
* HTML Forms
* Input Fields
* Buttons

## 📝 Form Fields

| Field        | Input Type | Required |
| ------------ | ---------- | -------- |
| First Name   | Text       | No       |
| Last Name    | Text       | No       |
| Phone Number | Number     | No       |
| Email ID     | Email      | Yes      |
| File Upload  | File       | No       |
| Date         | Date       | No       |
| Time         | Time       | No       |

## 📂 Project Structure

```text
project/

```

## 🚀 How to Run

1. Clone the repository.

2. Open the project folder.

3. Open the `form.html` file in any web browser.

4. Fill in the application form.

5. Click the **Submit** button.
